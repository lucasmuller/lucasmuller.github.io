Cisco, 2iQ, and DE-CIX are extracted from their official inline header SVGs. SVG viewBoxes were supplied where needed for responsive scaling; 2iQ and KTH white fills were changed to dark fills without changing geometry. Raster pixels are unchanged and carry source metadata. The component applies proportional sizing and theme-aware monochrome treatment in CSS, preserving tonal artwork and blending white raster backgrounds with the page.

Microsoft uses its official corporate wordmark with a separate Research caption, following its research website's naming. Inria uses its official institutional logo with a separate Paris caption; KAUST's official header symbol has a separate KAUST caption. These captions are UI text, not reconstructed logos.

ThousandEyes and Meraki use unchanged official SVG assets; the existing CSS applies theme-aware monochrome treatment.

To add an institution, save its official asset here and add its name, destination, filename, and display dimensions to `src/app/institutions.ts`. Keep this source list updated. The two ticker groups are derived from that single list.
